# Google Material Symbols

`material-symbols-outlined.woff2` is an unmodified, officially generated Google Fonts subset of Material Symbols Outlined (24 px optical size, weight 400, fill 0, grade 0).

Source: https://fonts.googleapis.com/css2?family=Material+Symbols+Outlined:opsz,wght,FILL,GRAD@24,400,0,0&icon_names=add,arrow_back,check,check_circle,chevron_right,delete,edit,error,expand_more,info,notifications,settings,volume_up,warning&display=block

Downloaded from the font URL supplied by that stylesheet on 2026-10-22. The font is bundled locally; the extension makes no Google Fonts requests at runtime.
